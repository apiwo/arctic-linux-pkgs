Using this mirror

Point a repo entry in /etc/alpm/repos.d/ at a folder under /ALL/ and alpm fetch will pick it up. Kernel and firmware packages are too large for this mirror — get those from the ISO or a GitHub release.

Not everything here is compiled. See yo.txt.
